# Skill IT Education — Advanced Cyber Security Certification Program

Static website content for the Cybersecurity course pages at `skilliteducation.com/courses/Cybersecurity/`.

## Structure

- `index.html` — Course Overview (Advanced Cyber Security Certification Program)
- `module-1-cybersecurity-foundations/` through `module-6-security-operations-cyber-defense/` — the six module pages
- `assets/css/style.css` — shared stylesheet
- `assets/img/` — program diagram
- `sitemap.xml` — machine-readable sitemap
- `SITEMAP.md` — human-readable sitemap and page-structure notes

## Preview locally

```bash
python3 -m http.server 8765
```

Then open `http://localhost:8765/index.html`.
