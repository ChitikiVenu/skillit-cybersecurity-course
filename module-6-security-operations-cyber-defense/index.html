Module 6 — Security Operations & Cyber Defense (2 Weeks)

The program closes on the Blue Team side of the discipline — how a Security Operations Center actually runs. Alert triage, incident response and executive reporting, built on the same findings you've spent the program learning to produce.

Students consolidating offensive skills into defensive and operational capability ahead of SOC-track and analyst roles.

Curriculum

What You Will Learn

A detailed, industry-aligned breakdown of every topic covered in this module.

  • Security Operations Center (SOC) structure, roles and workflows
  • SIEM fundamentals — log collection, correlation and alerting
  • Threat detection and anomaly-based monitoring techniques
  • Phishing detection and email security controls
  • Malware analysis workflows within a SOC context
  • Incident response process — detection, containment, eradication, recovery
  • Building and executing incident response playbooks
  • Vulnerability classification and CVSS-based prioritisation
  • Threat intelligence fundamentals and intelligence-led defence
  • Security monitoring tool configuration and tuning
  • Professional security reporting and executive documentation
  • Blue Team vs Red Team operational concepts
  • Building and maintaining a vulnerability prioritisation dashboard
